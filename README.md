# Фактчекинг: поймай предателя

Браузерная командная игра на логику, критическое мышление и медиаграмотность для трёх игроков. В онлайн-режиме у каждого игрока свой экран, а этапы и публикация синхронизируются между устройствами. Это статическая страница без своей сборки и сервера; для входа по короткому коду используется PeerJS Cloud. Интернет необходим; без PeerJS/CDN комнаты не подключатся. Игровые данные хранятся в памяти страницы; после перезагрузки комнату нужно создать заново.

## Онлайн-игра на отдельных устройствах

1. Ведущий выбирает **Создать онлайн-комнату** и решает, будет ли сам играть или только вести.
2. Когда комната готова, ведущий копирует ссылку-приглашение и отправляет её игрокам.
3. Игрок открывает ссылку — страница автоматически подключит его к комнате и назначит временное имя.
4. Когда игроки подключились, ведущий нажимает **Начать игру**. Перед запуском ведущий при желании может переименовать игроков. Ходы, таймер и новости синхронизируются автоматически.
5. Не закрывайте вкладки до конца игры. После обновления страницу нужно подключить заново.

PeerJS Cloud используется только для обмена сигналами подключения; игровые данные идут между браузерами. Нужен интернет и доступ к CDN. Бесплатный публичный сервис может быть недоступен или ограничен.

## Как играть

В каждом круге участники играют три роли: **Источник информации** сообщает правдивый личный факт, **Редактор новостей** превращает его в публикацию с помощью карточек-ловушек, а **Независимый расследователь** допрашивает игроков и ищет искажения и предателя. Источник и редактор случайно получают по одной секретной роли — «Правдивый» и «Предатель»; роли остаются закрытыми до раскрытия. Ведущий управляет этапами; игроки общаются голосом в видеоконференции. На допросе ответы — только «Да» или «Нет».

В игре предусмотрены семь этапов с таймерами, случайное вытягивание семи карточек-ловушек, приватная доставка секретных ролей владельцам, подсчёт очков и турнир на 1–5 кругов. После каждого круга участники переходят на следующую роль: Источник → Редактор → Расследователь → Источник. Таймер допроса можно настроить от 5 до 7 минут.

Очки: расследователь получает +3 за верно найденного предателя, +1 за каждое подтверждённое ведущим верно найденное искажение и +2 за объяснение сомнений; предатель получает +3, если расследователь не нашёл его; редактор получает +2 за выполнение всех вытянутых карточек-ловушек. На этапе вердикта ведущий отмечает, что расследователь назвал искажением и что действительно было искажено, чтобы игра начислила очки за правильные ответы.

## Как выложить на GitHub Pages

1. Зарегистрируйтесь на [github.com](https://github.com), если у вас ещё нет аккаунта.
2. Нажмите **+** в правом верхнем углу → **New repository**.
3. Введите имя репозитория `фактчекинг`, выберите **Public** и нажмите **Create repository**.
4. В новом репозитории выберите **Add file** → **Upload files**.
5. Перетащите в окно файл `index.html` и нажмите **Commit changes**.
6. Откройте **Settings** → вкладку **Pages**.
7. В разделе сборки выберите **Deploy from a branch**, затем **Branch: main** и папку **/(root)**, после чего нажмите **Save**.
8. Через 1–2 минуты игра будет доступна по адресу `https://<ваш-логин>.github.io/фактчекинг/`. Вместо `<ваш-логин>` укажите свой логин GitHub. Ссылку можно отправить друзьям.

> Если GitHub или браузер не принимает кириллицу в названии репозитория, используйте латинское имя, например `factchecking`; тогда замените последний сегмент адреса на `factchecking`.

## Как играть на видеоконференции

1. Начните видеоконференцию для голосового общения. Каждый игрок открывает страницу игры на своём устройстве.
2. Ведущий выбирает «Создать онлайн-комнату» и решает, играет ли сам или только ведёт игру.
3. Ведущий отправляет игрокам ссылку-приглашение. Игрок открывает её, и страница подключается автоматически. Вкладки нужно оставить открытыми.
5. Ведущий настраивает число кругов и таймер допроса, затем запускает раунд. Этапы автоматически появляются на экранах игроков.
6. Секретные роли приходят только их владельцам. Источник передаёт факт редактору лично, а ведущий вводит факт и скрывает его.
7. Редактор получает карточки-ловушки, готовит публикацию и передаёт её ведущему для ввода. Расследователь задаёт вопросы голосом; отвечать можно только «Да» или «Нет».
8. Расследователь объявляет вердикт, ведущий отмечает его и нажимает «Раскрытие». Игра синхронизирует результат и баллы. После круга поменяйтесь ролями!
